3개의 모듈, 하나의 플랫폼

마케팅 도구와 CRM 사이를 오갈 필요가 없습니다. 데이터가 진정으로 연결됩니다.

우리의 포지셔닝: 조직 인텔리전스(Organizational Intelligence)

SiliMind은 개인 오피스 어시스턴트가 아닙니다(Workbody류 제품처럼 한 사람의 일정을 관리하고 이메일을 작성하는 것이 아니라), 전체 조직을 AI가 작동하게 만듭니다——36명의 디지털 직원이 분업 협력하고, 능동적으로 감지하고, 자율적으로 실행합니다.

🧍 개인 오피스 어시스턴트(Workbody형)

  • 한 직장인에게 서비스
  • 하나의 Copilot 대화창, 물어야 답함
  • 개인 노트와 대화 기억
  • 가치=개인 생산성 향상

🏢 SiliMind 조직 인텔리전스

  • 전체 조직에 서비스——36명 디지털 직원으로 구성된 팀
  • 능동적으로 작동——자동 순찰/채널 대기/제안 푸시, 부르지 않아도 작동
  • 조직 기억——고객 상호작용이 지식 베이스로 축적, 전원 공유
  • 조직 의사결정——데이터가 사람을 찾아가고, 상업 기회 건강도·어트리뷰션 분석

SiliMind은 콘텐츠 리드 확보, 리드 관리, 상업 기회 팔로우업, 계약 성과를 한 플랫폼에 담습니다. AI가 모든 단계를 관통합니다——주제 선정, 콘텐츠 작성, 고객 팔로우업, 회의록 생성, 데이터 분석을 지원합니다. '한 편의 SEO 아티클이 가져온 리드'부터 '이 성과의 금액'까지 전체를 추적할 수 있습니다.

📢마케팅 리드 확보

'무엇을 써야 할지 모르는'부터 '어떤 콘텐츠가 성과를 가져왔는지'까지 전체를 추적할 수 있습니다.

AI 주제 선정 센터

업종 키워드를 입력하면 AI가 검색량 추정치, 경쟁 난이도, 기회 점수가 포함된 주제 10개를 반환합니다. 감으로 쓸 주제를 정하지 말고 검색 데이터가 판단하게 하세요. 매주 월요일 자동으로 '금주 주제 보고서'를 푸시합니다——지난주 콘텐츠의 검색 순위 변화와 업계 트렌드 기반.

콘텐츠 워크벤치

3열 칸반(초안→검토 대기→발행됨)으로 모든 콘텐츠를 관리합니다. AI가 주제에 따라 초안을 자동 생성하고, 편집기에 SEO 실시간 점검 패널이 내장되어 있습니다——키워드 밀도, H 태그 구조, 내부 링크 제안, 가독성 점수. 검토 통과 콘텐츠는 통일 배포 흐름으로 진입합니다——서드파티 배포 서비스(이샤오얼, Zernio 등)와 연동 개발이 완료되었으며, 자격 증명 연결 후 국내외 여러 플랫폼을 커버합니다.

효과 어트리뷰션 대시보드

Sankey 다이어그램이 콘텐츠 발행→페이지 방문→리드 문의→리드 입력→상업 기회 생성→성과의 전체 데이터 흐름을 표시합니다. ROI 리더보드는 '가져온 성과 금액'순으로 정렬되어, 마케팅 팀이 처음으로 '어떤 콘텐츠가 실제로 돈을 가져왔는지'를 봅니다.

멀티채널 메시지 통합

WhatsApp, Email, Telegram, Instagram, Messenger, LinkedIn 메시지가 고객 360° 타임라인에 자동 집중됩니다; 전화, 메모, WeChat, 기업용 WeChat 상호작용도 하나의 타임라인에 수동 기록 가능합니다——여러 앱을 전환할 필요가 없습니다.

💼영업 관리

통일 리드 풀, 상업 기회 칸반, 고객 360° 프로필, 방문 회의록 자동 생성, 계약 스마트 관리. 모든 채널 메시지가 한곳에 모이며, 영업 담당자가 바뀌어도 정보가 사라지지 않습니다.

통일 리드 풀

콘텐츠 폼, 채널 메시지, AI 능동 확보, 전시회 가져오기 리드가 모두 한곳에 모입니다; AI가 규칙에 따라 자동 점수(0-100)를 매기고 고가치 리드가 우선 표시됩니다; 자동 귀속이 불가능한 메시지는 '미배정 수신함'으로 들어가 관리자가 원클릭으로 수령·지정하며, 배정 결과가 실시간으로 담당자에게 알림됩니다.

🧹 데이터 중복 제거, 원클릭 병합

같은 고객이 '구호'와 '구호 로봇틱스'로 입력되었나요? 시스템이 회사명 유사도로 의심 중복 회사를 자동으로 찾아내고, 같은 회사 내에서는 이름·이메일로 중복 연락처를 매칭합니다. 병합을 확인하면 상호작용, 상업 기회, 작업, 방문 기록, 계약 템플릿 등 관련 데이터가 모두 마스터 레코드로 이전되고 변경 기록이 남습니다. 여러 중복 쌍을 선택해 일괄 병합을 지원하며 쌍별 성공/실패 결과를 반환하여 데이터 정제를 한 번에 완료합니다.

  • 스마트 유사성 감지: 회사명 유사도 가중 비교, 짧은 이름이 긴 이름에 포함된 경우('구호'→'구호 로봇틱스')도 인식
  • 병합即이전: 연락처, 상업 기회, 상호작용, 작업, 태그, 방문 보고서, 계약 템플릿이 마스터 레코드와 함께 모두 이전되며 변경 기록이 남습니다

상업 기회 칸반

5단계(신규 문의→팔로우업→견적→수주→유실), 드래그로 진행. 각 상업 기회 카드는 의사결정에 필요한 정보만 표시: 고객 회사, 금액, 마지막 팔로우업 이후 일수(>3일 주황, >7일 적색); 수주/유실 시간과 유실 사유가 자동 기록되고, 성사 확률은 AI가 직접 읽고 씁니다. 클릭하여 상세 페이지로 이동하면 대화 타임라인 + AI 사이드바(고객 핵심 니즈, 예산 범위, 권장 다음 단계 자동 추출).

고객 360° 프로필

3개 탭 뷰: '영업 터치포인트'는 모든 채널 메시지의 타임라인을 표시(감성 태그 포함); '마케팅 터치포인트'는 리드 전환 전 콘텐츠 상호작용을 표시; 'AI 인사이트'는 종합 프로필과 리스크 경고를 제공합니다. 상업 기회 건강도 점수(0-100)가 프로필에 내장: 커뮤니케이션 빈도, 감성 추세, 단계 체류, 주도 비율, 금액 5개 차원으로 자동 계산되어 녹색 건강/노란색 주시/적색 경고.

방문 관리

녹음을 업로드하면 AI가 1분 만에 구조화된 회의록을 생성합니다(13개 업무 필드: 안건, 요약, 핵심 포인트, 고객 피드백, 다음 액션 등). 방문 캘린더는 월/주 뷰 전환을 지원하며 드래그로 날짜 조정 가능.

계약 및 견적

AI가 대화 기록에서 계약 필드를 자동 추출해 템플릿을 채우고, 승인 프로세스(초안→승인 대기→효력 발생). 견적 편집기는 제품 선택, 통화 변환, PDF 내보내기를 지원하며 상업 기회와 대화 타임라인에 자동 연동됩니다.

AI 제안 센터

8가지 시그널이 영업 전 시나리오를 커버: 휴면 고객 재활성화, 정체 상업 기회 추진, 고가치 상업 기회 경고, 기한 임박 작업 알림, 방문 후 미팔로우업, 방문 임박 준비, 인기 이메일 식별, 부정 감성 경고. 각 제안 카드에는 '채택'과 '무시' 버튼이 있으며, 채택 시 작업이 자동 생성되거나 상업 기회 단계가 진행됩니다.

ChatBI 스마트 Q&A

자연어로 데이터를 조회하고 AI가 차트를 자동 생성합니다(막대/원형/추세선), 원클릭 내보내기 지원. '지난달 어떤 채널의 성과 금액이 가장 높았나요?' '장삼과 이사의 상업 기회 전환율 비교'——SQL을 배울 필요 없이 바로 물어보세요.

관리 대시보드

전사 수준 지표: 영업 퍼널, 마케팅 투자와 ROI(플랫폼/채널/콘텐츠 제작 등 비용 입력 지원, 성과 금액÷투자 자동 계산), 팀 실적 순위, 리드 확보 채널 효과. AI가 능동적으로 경고: 리드 수 감소, 고가치 상업 기회 정체, 영업 응답 속도가 평균 이하. AI 사용량 투명: 8가지 AI 기능(ChatBI/추천/메시지 분석/계약/프로필/방문/지식 베이스/주제 등)별로 토큰 소비, 호출 횟수, 평균 소요 시간과 모델 분포를 통계하여 AI 투입 내역을 한눈에 확인합니다(비용은 사용 모델 가격으로 자체 계산).

상업 기회 건강도 점수

5개 차원 자동 점수: 커뮤니케이션 빈도, 감성 추세, 단계 진행 속도, 능동 연락 비율, 금액 가중치. 녹색(70-100) 건강, 노란색(40-69) 주시, 적색(0-39) 경고.

핵심 기술

  • 약 600개 API 엔드포인트(2026-10 점검 595개), 50+ 데이터 테이블로 마케팅·영업 전 프로세스 완전 커버
  • 멀티채널 메시지 접수: WhatsApp / Email / Telegram / Instagram / Messenger / LinkedIn 6개 채널 자동 수집 입력; WeChat, 기업용 WeChat, 전화 등 상호작용은 타임라인 통일 기록·표시 지원
  • RAG 지식 베이스: PDF/Word/Markdown/URL 업로드 시 AI가 자동 인덱싱하고, 메시지 옆에 기술 문의 응답 초안 생성(인용 출처, 세미오토메이션 모드)
  • 가져오기 자동 중복 제거 병합으로 데이터가 쓸수록 깨끗해집니다
  • 온프레미스 배포: 데이터가 완전히 기업 내부에 있으며, PostgreSQL + Redis 프로덕션 배포 지원
