MCP

AI 어시스턴트를 CRM에 연결

SiliMind는 MCP(Model Context Protocol)를 지원합니다——AI 어시스턴트가 외부 도구를 사용하는 표준 프로토콜입니다. AI 어시스턴트는 SiliMind CRM을 직접 읽고(쓰기는 승인 필요) 활용할 수 있습니다.

연결 대상

🤖

Claude Desktop

딜·고객·작업을 Claude에게 바로 물어보기

💬

ChatGPT

커스텀 GPT를 통해 파이프라인 조회

⚙️

Cursor / 모든 MCP 클라이언트

SiliMind 데이터 위에 자체 AI 워크플로우 구축

AI가 할 수 있는 일

🔍 고객 검색“Acme Corp의 모든 연락처를 찾아줘”
📊 딜 확인“내 후속 파이프라인에는 뭐가 있어?”
📅 일정 확인“내일 일정 뭐 있어?”
📝 작업 생성“John에게 후속 작업 추가해줘”(SiliMind 내 승인 필요)
🧠 자연어 질의허용된 데이터 범위 내 무엇이든 질문

3단계로 연결

STEP 1 · 토큰 발급

SiliMind → 설정 → MCP Access → Generate에서 MCP 토큰을 발급합니다.

STEP 2 · Claude Desktop에 추가

아래 설정을 Claude Desktop 설정 파일에 추가:

{
  "mcpServers": {
    "silimind": {
      "command": "python",
      "args": ["-m", "silimind_mcp.stdio_bridge"],
      "env": {
        "SILIMIND_URL": "https://agent.silimind.net",
        "SILIMIND_TOKEN": "smcp_your_token"
      }
    }
  }
}
STEP 3 · 바로 질문

“Hey Claude, what are my top deals this week?”

API

REST API

모든 엔드포인트는 Bearer 토큰 인증을 사용하며, 핵심 리소스 CRUD, AI 제안, 지식 베이스 시맨틱 검색을 제공합니다.

Base URL: https://agent.silimind.net/api

인증

POST /api/auth/login
Content-Type: application/json

{
  "email": "you@company.com",
  "password": "your_password"
}

Response:

{
  "accessToken": "eyJhbGciOiJIUzI1NiIs...",
  "tokenType": "bearer",
  "role": "sales"
}

이후 모든 요청에 토큰을 포함하세요:

Authorization: Bearer eyJhbG…s...

핵심 리소스

고객 Contacts

MethodEndpointDescription
GET/contactsList contacts (paginated, searchable)
POST/contactsCreate a contact
GET/contacts/{id}Get contact detail
PUT/contacts/{id}Update a contact
DELETE/contacts/{id}Delete a contact

회사 Companies

MethodEndpointDescription
GET/companiesList companies
POST/companiesCreate a company
GET/companies/{id}Get company detail
PUT/companies/{id}Update
DELETE/companies/{id}Delete

딜 Deals

MethodEndpointDescription
GET/dealsList deals
POST/dealsCreate a deal
GET/deals/{id}Get deal detail
PUT/deals/{id}Update deal (stage, amount, etc.)
DELETE/deals/{id}Delete

MethodEndpointDescription

MethodEndpointDescription

예시 — 고객 검색

GET /api/contacts?q=acme&page=1&page_size=20
Authorization: Bearer <your-token>

Authorization: Bearer <your-token>

스트리밍 SSE 응답.

지식 베이스

MethodEndpointDescription
GET/knowledge/docsList documents
POST/knowledge/docs/uploadUpload document (PDF/DOCX/MD)
POST/knowledge/searchSemantic search

예시 — 시맨틱 검색

POST /api/knowledge/search
Content-Type: application/json
Authorization: Bearer <your-token>

{"query": "产品规格参数", "top_k": 5}

응답 규약

  • 성공 — 200 / 201(생성)
  • 인증 실패 — 401 — 토큰 만료 또는 무효
  • 권한 없음 — 403
  • 찾을 수 없음 — 404
  • 검증 오류 — 422, 필드 상세 포함
  • 레이트 리밋 — 429

페이지네이션

목록 엔드포인트는 page 및 page_size 쿼리 파라미터를 사용합니다(기본 20, 최대 100).

레이트 리밋

  • 토큰 단위 레이트 리밋 적용
  • 초과 시 Retry-After 헤더와 함께 429 반환
