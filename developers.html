MCP

把 AI 助手连上你的 CRM

SiliMind 支持 MCP（Model Context Protocol）——AI 助手使用外部工具的标准协议。你的 AI 助手可以直接读取（并在你批准后写入）你的 SiliMind CRM。

能连什么

🤖

Claude Desktop

直接问 Claude 你的商机、客户、任务

💬

ChatGPT

通过自定义 GPT 查询你的销售管线

⚙️

Cursor / 任意 MCP 客户端

在 SiliMind 数据上构建你自己的 AI 工作流

你的 AI 能做什么

🔍 搜索客户“找出 Acme Corp 的所有联系人”
📊 查商机“我跟进中的管线有哪些？”
📅 看日程“我明天有什么安排？”
📝 建任务“给 John 加一条跟进任务”（需你在 SiliMind 内批准）
🧠 自然语言查询关于你被授权数据的任何问题

三步接入

STEP 1 · 获取 token

SiliMind → 设置 → MCP Access → Generate，生成你的 MCP token。

STEP 2 · 添加到 Claude Desktop

把下面的配置加入 Claude Desktop 配置文件：

{
  "mcpServers": {
    "silimind": {
      "command": "python",
      "args": ["-m", "silimind_mcp.stdio_bridge"],
      "env": {
        "SILIMIND_URL": "https://agent.silimind.net",
        "SILIMIND_TOKEN": "smcp_your_token"
      }
    }
  }
}
STEP 3 · 直接提问

“Hey Claude, what are my top deals this week?”

安全设计

🔒 每个 token 独立权限readonly / readwrite 两种粒度
🔒 租户隔离你的 AI 只能看到你的数据
🔒 限流 + 全量审计日志每次调用可追溯
🔒 写入需你批准AI 提议，你在 SiliMind 内确认

API

REST API

全部端点基于 Bearer token 认证，覆盖核心资源 CRUD、AI 建议与知识库语义检索。

Base URL: https://agent.silimind.net/api

认证

POST /api/auth/login
Content-Type: application/json

{
  "email": "you@company.com",
  "password": "your_password"
}

Response:

{
  "accessToken": "eyJhbGciOiJIUzI1NiIs...",
  "tokenType": "bearer",
  "role": "sales"
}

后续所有请求携带：

Authorization: Bearer eyJhbG…s...

Authorization: Bearer <your-token>

知识库

MethodEndpointDescription
GET/knowledge/docsList documents
POST/knowledge/docs/uploadUpload document (PDF/DOCX/MD)
POST/knowledge/searchSemantic search

示例 — 语义搜索

POST /api/knowledge/search
Content-Type: application/json
Authorization: Bearer <your-token>

{"query": "产品规格参数", "top_k": 5}

响应约定

  • 成功 — 200 / 201（创建）
  • 认证失败 — 401 — token 过期或无效
  • 无权限 — 403
  • 不存在 — 404
  • 参数校验失败 — 422，附字段详情
  • 触发限流 — 429

分页

列表端点使用 page 与 page_size 查询参数（默认 20，最大 100）。

限流

  • 按 token 维度限流
  • 超限返回 429，并附 Retry-After 响应头
