MCP

AI アシスタントを CRM につなぐ

SiliMind は MCP（Model Context Protocol）に対応——AI アシスタントが外部ツールを使う標準プロトコルです。AI アシスタントは SiliMind CRM を直接読み取り（書き込みはあなたの承認が必要）できます。

Cursor / 任意の MCP クライアント

AI にできること

🔍 顧客を検索“Acme Corp の連絡先をすべて探して”
📊 商談を確認“フォローアップ中のパイプラインは？”
📅 予定を確認“明日のスケジュールは？”
📝 タスクを作成“John にフォローアップタスクを追加”（SiliMind 内での承認が必要）
🧠 自然言語で照会許可されたデータ範囲になんでも質問

3 ステップで接続

STEP 1 · トークンを取得

SiliMind → 設定 → MCP Access → Generate で MCP トークンを発行。

STEP 2 · Claude Desktop に追加

以下の設定を Claude Desktop の設定ファイルに追加：

{
  "mcpServers": {
    "silimind": {
      "command": "python",
      "args": ["-m", "silimind_mcp.stdio_bridge"],
      "env": {
        "SILIMIND_URL": "https://agent.silimind.net",
        "SILIMIND_TOKEN": "smcp_your_token"
      }
    }
  }
}
STEP 3 · そのまま質問

“Hey Claude, what are my top deals this week?”

セキュリティ設計

🔒 トークンごとの権限readonly / readwrite の 2 種類
🔒 テナント分離あなたの AI はあなたのデータだけを見る
🔒 レート制限 + 完全監査ログすべての呼び出しを追跡可能
🔒 書き込みには承認が必要AI が提案し、あなたが SiliMind 内で承認

API

REST API

すべてのエンドポイントは Bearer トークン認証。コアリソース CRUD、AI 提案、ナレッジベースのセマンティック検索をカバーします。

Base URL: https://agent.silimind.net/api

認証

POST /api/auth/login
Content-Type: application/json

{
  "email": "you@company.com",
  "password": "your_password"
}

Response:

{
  "accessToken": "eyJhbGciOiJIUzI1NiIs...",
  "tokenType": "bearer",
  "role": "sales"
}

以降のリクエストにはこのトークンを付与：

Authorization: Bearer eyJhbG…s...

レスポンス規約

  • 成功 — 200 / 201（作成）
  • 認証失敗 — 401 — トークン期限切れまたは無効
  • 権限なし — 403
  • 見つからない — 404
  • バリデーションエラー — 422（フィールド詳細付き）
  • レート制限 — 429

ページネーション

一覧エンドポイントは page と page_size クエリパラメータを使用（デフォルト 20、最大 100）。

レート制限

  • トークン単位でレート制限を適用
  • 超過時は Retry-After ヘッダー付きの 429 を返却
