MCP

Connect your AI assistant to your CRM

SiliMind speaks MCP (Model Context Protocol) — the standard way for AI assistants to use external tools. Your assistant can directly read (and, with your approval, write to) your SiliMind CRM.

Connect in three steps

STEP 1 · Get your token

SiliMind → Settings → MCP Access → Generate.

STEP 2 · Add to Claude Desktop

Add this to your Claude Desktop config:

{
  "mcpServers": {
    "silimind": {
      "command": "python",
      "args": ["-m", "silimind_mcp.stdio_bridge"],
      "env": {
        "SILIMIND_URL": "https://agent.silimind.net",
        "SILIMIND_TOKEN": "smcp_your_token"
      }
    }
  }
}
STEP 3 · Ask away

“Hey Claude, what are my top deals this week?”

API

REST API

All endpoints use Bearer token auth and cover core-resource CRUD, AI suggestions and knowledge-base semantic search.

Base URL: https://agent.silimind.net/api

Authentication

POST /api/auth/login
Content-Type: application/json

{
  "email": "you@company.com",
  "password": "your_password"
}

Response:

{
  "accessToken": "eyJhbGciOiJIUzI1NiIs...",
  "tokenType": "bearer",
  "role": "sales"
}

Use the token in all subsequent requests:

Authorization: Bearer eyJhbG…s...

Example — semantic search

POST /api/knowledge/search
Content-Type: application/json
Authorization: Bearer <your-token>

{"query": "产品规格参数", "top_k": 5}

Response conventions

  • Success — 200 / 201 (created)
  • Auth failure — 401 — token expired or invalid
  • Permission denied — 403
  • Not found — 404
  • Validation error — 422 with field details
  • Rate limit — 429

Pagination

List endpoints use page and page_size query parameters (default: 20, max: 100).

Rate limits

  • Per-token rate limiting applies
  • Exceeding limits returns 429 with a Retry-After header
